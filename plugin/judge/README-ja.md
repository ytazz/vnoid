# VnoidJudgeプラグイン

VnoidJudge プラグインは、ヒューマノイドバーチャルアスレチック競技（HVAC）の自動判定を行う Choreonoid プラグインです。シミュレーション中にロボットの状態を監視し、以下の判定・表示を行います。

- 合計質量のチェック（下限値以上であること）
- 関節パワー（POWER）の監視と上限超過の検出
- ロボットのバウンディングボックス（BB）寸法の監視と上限超過の検出
- フィールドの各セクションのクリア判定とクリアタイムの記録
- 判定状況のシーンビューへの HUD 表示とセクション領域の可視化
- 判定結果のテキストファイル保存

## ビルド方法

本プラグインは vnoid リポジトリの一部として、Choreonoid のビルドに組み込む形でビルドします。

1. Choreonoid ソースディレクトリの `ext` ディレクトリに vnoid リポジトリを clone します
2. Choreonoid の CMake のビルド設定で `VNOID_BUILD_CNOID` と `BUILD_VNOID_JUDGE_PLUGIN` を ON にします
3. Choreonoid をビルドします

なお、本プラグインは Choreonoid 本体のコミット `cb45151ae`（2026-07-05）以降のバージョンと組み合わせる必要があります。

## 構成要素

| 要素 | 役割 |
|---|---|
| Vnoid判定対象アイテム（VnoidJudgeTargetItem） | 判定対象のロボットを指定するアイテム。ロボットの BodyItem の子として配置すると、そのロボットに判定用デバイス（VnoidJudgeTargetDevice）を装着します。判定の制限値（競技ルールのパラメータ）もこのアイテムが保持します。 |
| Vnoid判定アイテム（VnoidJudgeItem） | 判定を実行する「審判」アイテム。シミュレータアイテムの子として配置します。シミュレーション中の判定処理と、HUD・セクション BB の表示を担当します。 |
| VnoidJudgeTargetDevice | 判定状態（パワー、BB、経過時間、セクション状態）を保持する内部デバイス。Vnoid判定対象アイテムが自動的に装着するため、ユーザーが直接操作する必要はありません。状態はデバイス状態記録の仕組みでフレームごとに記録され、再生時にも判定表示が再現されます。 |

## セットアップ手順

1. ワールドアイテムの下に、ロボットの BodyItem とフィールドの BodyItem を配置した通常のシミュレーションプロジェクトを用意します
2. ロボットの BodyItem の子として Vnoid判定対象アイテムを配置します（BodyItem を選択した状態で、メインメニューの「ファイル」-「新規」-「Vnoid判定対象」で作成できます）
3. 必要に応じて Vnoid判定対象アイテムのプロパティで制限値を設定します
4. シミュレータアイテムの子として Vnoid判定アイテムを配置します（シミュレータアイテムを選択した状態で「ファイル」-「新規」-「Vnoid判定」）
5. アイテムツリー上で Vnoid判定アイテムに**チェックを入れます**

**注意: HUD やセクションバウンディングボックスなどのシーンビュー上の判定表示は、Vnoid判定アイテムのチェックが入っていないと一切表示されません**。シミュレーションを実行しても判定結果が画面に出ないときは、まず Vnoid判定アイテムのチェックを確認してください。

逆に、HUD 表示が邪魔なときは、チェックを外すことであえて表示を消すこともできます。チェックの有無は表示だけを切り替えるものであり、チェックを外していても判定処理自体はちゃんと実行され、結果の記録やメッセージ出力、判定結果のファイル保存も通常どおり行えます。

アイテムツリーの構成例:

```
World
 ├─ SR1 (BodyItem)
 │   ├─ SimpleController (任意のコントローラアイテム)
 │   └─ JudgeTarget (Vnoid判定対象アイテム)
 ├─ HVAC2023_athletics_field (BodyItem)
 └─ AISTSimulator (任意のシミュレータアイテム)
     └─ VnoidJudge (Vnoid判定アイテム)
```

シミュレーションを開始すると判定が始まり、開始時に合計質量のチェック結果がメッセージビューに表示されます。セクションのクリアや制限値の超過が発生すると、その都度メッセージビューに通知されます。

## フィールドのセクション定義

セクションクリア判定の対象となるセクションは、フィールドの body ファイルの**トップレベル**（`links:` などと同じ階層）に `hvac_field_sections` として記述します。プラグインはセクションの個数や構成を決め打ちせず、この定義だけを参照します。

```yaml
hvac_field_sections:
  - name: "Section1-Easy"
    pre_stage_bb:
      - [ -0.75, -2.0, -0.2 ]
      - [ 0.75, 2.2, 4.0 ]
    section_bb:
      - [ 0.75, 0.0, -0.2 ]
      - [ 5.25, 2.2, 4.0 ]
    post_stage_bb:
      - [ 5.25, -2.0, -0.2 ]
      - [ 6.75, 2.2, 4.0 ]
  - name: "Section1-Hard"
    ...
  - new_row
  - name: "Section2-Easy"
    ...
```

- `name`: セクション名。HUD のラベルや結果ファイルにそのまま表示されます
- `pre_stage_bb` / `section_bb` / `post_stage_bb`: 前ステージ・セクション・後ステージのワールド座標での軸並行バウンディングボックス。最小点と最大点の2点で指定します
- `new_row`: これを挟むと、以降のセクションが HUD 表示で次の段に配置されます（判定には影響しません）。`new_row` を使わない場合は3列で自動折り返しされます
- セクション数の上限は8個です。リスト中の記述順がそのまま内部の管理順になります

セクションのバウンディングボックスを作成・編集する際は、あらかじめ Choreonoid 上でプロジェクトの構成を作り、Vnoid判定アイテムのバウンディングボックス表示（「セクションバウンディングボックスの表示」プロパティ）を有効にしておくと便利です。テキストエディタで body ファイルを編集するたびに、フィールドの Body アイテムを再読込（コンテキストメニューの「再読み込み」または Ctrl + R）すれば、編集したバウンディングボックスがすぐにシーンビュー上で可視化されるので、座標値を確認しながら効率よく編集できます。また、HUD のセクション表示に各セクションの名前が並ぶことで、セクション定義自体が正しく書けて読み込まれているかどうかも確認できます。

## 判定の内容

### 質量チェック

シミュレーション開始時に、ロボットの全リンクの合計質量が下限値（「質量の下限値」プロパティ）以上かをチェックし、結果をメッセージビューに表示します。

### POWER（関節パワー）

各関節の |関節速度 × 関節トルク| を監視します。瞬時値のスパイクを避けるため、時間窓（「POWER平均時間窓」プロパティ、既定値 0.01 秒）での移動平均を取り、全関節の最大値を POWER とします。POWER の最大値が上限（「POWER上限」プロパティ）を超えると、超過した関節名とともにメッセージビューに通知され、HUD の POWER 表示が赤になります。

**POWER の計算を正しく行うためには、シミュレーションから関節トルクと関節速度が出力されている必要があります**。AISTSimulatorItem・PhysXSimulatorItem・MuJoCoSimulatorItem では、シミュレータアイテムのプロパティ「駆動トルク／力出力」を true にしておいてください。さらに PhysXSimulatorItem と MuJoCoSimulatorItem では、「速度出力」プロパティも true にしておく必要があります（AISTSimulatorItem では関節速度は常に出力されるため、このプロパティはありません）。なお、これら以外のシミュレータアイテムでの動作はテストしていません。

### バウンディングボックス（BB）

ロボットの BB は、各リンクのメッシュ頂点を凸包で縮約した点群から計算する、ルートリンク座標系での軸並行バウンディングボックスです。ロボット全体が回転しても箱が膨らまず、形状にタイトにフィットします。各軸の寸法の最大値が上限（「バウンディングボックスX/Y/Z上限」プロパティ）を超えると、メッセージビューに通知され、HUD の表示が赤になります。

**ロボットの BB をシーンビューに表示したい場合は、ロボットの BodyItem のプロパティ「バウンディングボックスの表示」を true にしてください**（Choreonoid 本体の機能です）。この表示に使われる BB は判定に使われるものと同じ定義です。

### セクションクリア判定

各セクションについて、以下の手順を踏むとクリアとなります。

1. ロボットの BB（ワールド座標）が前ステージの BB に完全に入る
2. セクションの BB に完全に入る（セクション挑戦中となる）
3. 後ステージの BB に完全に入り、そのまま1秒間滞在する → クリア。クリアタイムが記録されます

隣接する領域の境界をまたいでいる間（2つ以上の領域と交差している間）は判定が維持されます。交差している領域が1つだけのときは、その領域に完全に入っていることが求められ、コース外へのはみ出しは挑戦のリセットになります。セクション内から前ステージへ完全に戻った場合は、前ステージ待機状態に戻ります（クリア済みのセクションはリセットされません）。

## HUD 表示

Vnoid判定アイテムにチェックを入れると、シーンビューに以下が表示されます。

- 左上: POWER の現在値・最大値・超過関節、ロボット BB の各軸寸法（現在値と最大値）
- 右上: 経過時間（TIME）
- 下部中央: 各セクションの状態

セクションの状態表示は次のとおりです（色はセクション BB の可視化と連動しています）。

| 表示 | 意味 | 色 |
|---|---|---|
| `Section1-Easy:` | 待機中 | 通常色 |
| `Section1-Easy: PRE STAGE` | 前ステージに滞在中 | 水色 |
| `Section1-Easy: IN SECTION` | セクション挑戦中 | 黄 |
| `Section1-Easy: POST STAGE` | 後ステージに滞在中（1秒経過前） | オレンジ |
| `Section1-Easy: CLEAR 12.34s` | クリア（タイム付き） | 緑 |

フォントサイズ・文字色・パネル透明度は Vnoid判定アイテムのプロパティで変更できます。

判定状態は判定デバイスの状態としてフレームごとに記録されるため、シミュレーション後のプレイバック再生やタイムバーの操作にも連動して、**その時刻での判定状態**が HUD とセクション BB の表示に反映されます。

## セクション BB の可視化

Vnoid判定アイテムのプロパティ「セクションバウンディングボックスの表示」が true のとき（既定値）、各セクションの前ステージ・セクション・後ステージの BB がワイヤーフレームでシーンビューに表示されます。色は上記の状態と同じ色分けで、待機中はグレーです。シミュレーションを実行していなくても表示されるので、フィールドのセクション定義の確認にも使えます。

## 判定結果の保存

Vnoid判定アイテムのコンテキストメニュー（右クリック）から「判定結果をファイルに保存」を選ぶと、**その時点の再生状態**の判定結果をテキストファイルに保存できます。シミュレーションの最終結果を保存したい場合は、事前に再生を最終時刻まで進めてください（シミュレーション実行直後はそのままで最終状態です）。

デフォルトのファイル名は「プロジェクト名-result.txt」です。出力例:

```
Project: vnoid-judge-test
Target: SR1
Elapsed time: 30.000 s
Total mass: 45.000 kg (OK)
Power average window: 0.01 s
Max power: 350.2 W (joint RLEG_KNEE, ID 4) (OK)
Max bounding box: 0.512 0.605 1.630
BBox: OK
Section Section1-Easy: CLEAR at 12.340 s
Section Section2-Easy: CLEAR at 25.100 s
```

クリアしたセクションはクリア時刻順に列挙されます。クリアしたセクションがひとつもない場合は `No section has been cleared.` と出力されます。

スクリプトによる自動化のために、Vnoid判定アイテムには `saveJudgementResult(filename)` 関数が用意されており、ダイアログなしで現在の再生状態の結果を指定ファイルに保存できます。

## プロパティ一覧

### Vnoid判定対象アイテム

| プロパティ | 意味 | 既定値 |
|---|---|---|
| POWER上限 [W] | POWER の上限 | 1000.0 |
| 質量の下限値 | 合計質量の下限 [kg] | 30.0 |
| バウンディングボックスX/Y/Z上限 | BB 各軸寸法の上限 [m] | 2.0 |

### Vnoid判定アイテム

| プロパティ | 意味 | 既定値 |
|---|---|---|
| POWER平均時間窓 [s] | POWER の移動平均の時間窓 | 0.01 |
| セクションバウンディングボックスの表示 | セクション BB の可視化の有効化 | true |
| フォントサイズ | HUD のフォントサイズ | 18 |
| テキスト色 | HUD の文字色 | 白 |
| パネル透明度 | HUD パネルの透明度 | 0.4 |

## WorldLogFileItem によるログ保存

判定状態は判定デバイスの状態として記録されるため、WorldLogFileItem を用いてシミュレーションログをファイルに保存すると、判定結果のログも一緒に保存されます。ログを保存したプロジェクトを読み込み直した場合でも、WorldLogFileItem の再生によって判定状態（HUD・セクション BB の表示）が再現され、任意の再生時刻で判定結果のファイル保存を行うことができます。
